# 🔺 Prism — bend the light

A calm, tactile light puzzle. A beam pours from an **emitter** — rotate the
**mirrors** to bend it and **ignite every crystal**. No timer, no noise. Just you
and the light.

👉 **Play free:** https://rahulatrkm.github.io/prism/

## Why it feels good

Prism is built **UX-first**:

- **One-thumb play** — tap a mirror to rotate it; the beam re-solves instantly
- **Live light** — a glowing, pulsing beam traces in real time as you turn mirrors
- **Zero friction** — no accounts, no ads, no timer; pick up and put down anytime
- **Auto-progress** — your solved levels are remembered; jump back in where you left off
- **Built-in tutorial** — a How-to-Play guide with a legend for every piece; reopen it anytime with the **?** button
- **Gentle help** — a 💡 Hint highlights exactly one mirror to turn when you're stuck
- **Par challenge** — every level has a target move count for a perfect run
- **Buttery visuals** — mirrors physically spin, crystals bloom when lit, all on
  a crisp HTML5 canvas that scales to any screen

## How to play

- **Tap** a mirror to rotate it between `/` and `\`
- The beam reflects off mirrors, passes through crystals, and stops at walls/edges
- Light **all** crystals to clear the level
- **↺ Reset** to restore a level, **💡 Hint** if you're stuck, **☰** to jump levels

## Levels

**240 puzzles** that ramp from a single mirror on a 6×6 grid to multi-bounce
light mazes with 8 mirrors on a 9×9 grid. Every level is **machine-verified**:

- **Always solvable** — generated by tracing a real beam, dropping crystals onto
  its path, then scrambling the mirror orientations.
- **Never pre-solved** — the starting scramble is guaranteed *not* to already
  light every crystal, so there's always a real puzzle to solve.
- **Fair par** — each level's Par is the minimum number of rotations from the
  start to a valid solution.

## Tech

A single self-contained `index.html` — HTML5 Canvas + vanilla JavaScript. No
build step, no dependencies, no network calls, works offline. The beam is
ray-traced across the grid every interaction; mirrors animate their rotation;
crystals glow via canvas shadow blur. Progress persists in `localStorage`.
